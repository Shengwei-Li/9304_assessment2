这个模型是做什么的

它是水翼船的一台"虚拟样机"加上它的自动驾驶：你给一个想要的高度，控制器根据传感器读数去转动前后翼，让船飞到那个高度并保持水平，同时抵抗波浪。

高度指令→50 Hz 数字控制器（卡尔曼滤波 + LQR）→执行器（舵机）→ 船的运动→三个传感器→回到控制器

此外还有：

  • 波浪：同时扰动船（水流上下运动改变翼的迎角）和超声波传感器（波面起伏改变测到的高度）。
  • 线性模型：和非线性船体吃同样的翼角和波浪、并排运行，用来看线性化在什么范围内可信。

角度单位全部是弧度。翼角 delta 是绝对安装角；状态 x = [h; v; θ; q] 是相对配平点的偏差（升沉、升沉速度、俯仰角、俯仰角速度）。符号见 README.md 第 3 节。

顶层

分成三个带标题的区域，每个区域里信号都从左往右走。蓝色模块是物理系统，黄色是控制器，绿色是线性模型。

区域 1：闭环主回路

编号模块作用
1Trim u0常数，配平翼角 u0（约 3.53° 和 3.11°）。船要平飞，翼必须先有这个基础角度。
2Foil command额外的开环翼角指令 u_cmd_ts，默认为零。只在做开环测试（控制器关闭）时用。
3Height reference高度指令 r_ts：希望船比配平高度高多少米。默认第 1 秒升 5 cm。
4Controller50 Hz 数字控制器。三个输入：测量值、编码器读到的翼角、高度指令；输出翼角修正量 u_fb，以及控制器的估计值 xh 和通信统计 link（只用于记录和 3D 画面）。它是一个变体子系统：控制算法可以在模型里运行，也可以在另一个进程里通过 TCP 运行，由 ctrl_ext 选择。图标上方显示当前用的是哪一个。内部见下一节。
18Encoder记忆模块（取上一个计算步的值），初值为配平角。模拟编码器：控制器读到的是自己发出新指令之前的翼角。没有它时，"理想执行器"选项会形成代数环（指令在同一时刻又回到输入）。
5Sum cmd配平角 + 开环指令 + 控制器输出，得到要求的绝对翼角 u_cmd。
6Actuators舵机。把要求的翼角变成实际翼角 delta，有位置和转速限制。
7Nonlinear boat船的非线性动力学。输入实际翼角和波浪水流速度，输出四个状态 x。
8Waves迎浪（规则或不规则）。输出翼处的水流竖直速度 w 和传感器下方的波面高度 zeta_s。
9Sensor三个传感器，输出 y_meas = [船头高度；俯仰角；俯仰角速度]。
10log y_meas测量值存到 out.y_meas。

控制器 Controller（50 Hz 数字控制器）

这个子系统代表船上单片机里跑的程序。它是一个变体子系统，里面有两个可选的实现，同一时刻只有一个生效，由工作区变量 ctrl_ext 决定：

编号模块作用
1–3y_meas, delta, r输入：三个测量值、编码器读到的翼角（经顶层的 18 Encoder）、高度指令。
4Onboardctrl_ext = 0（默认）：控制算法在模型里运行。
5External (TCP)ctrl_ext = 1：控制算法在另一个 MATLAB 进程（ctrl_server.m）里运行，这里只负责收发数据。见软件在环。
6–8u_fb, xh, link输出：翼角修正量（相对配平角）；估计值；通信统计。

变体子系统这一层不能连线，Simulink 按端口名字自动把外面的输入输出接到生效的那个实现上。两个实现都是"原子子系统"，采样时间 p.Ts_ctrl = 20 ms：每 20 ms 读一次输入、算一次，输出在两次计算之间保持不变（零阶保持），和真实硬件一样。

Onboard：模型内的控制器

编号模块作用
4Digital controllerMATLAB Function 模块，只有一行：调用 digital_controller.m。所有算法都在那个文件里，下面逐步讲。参数 dc 来自 design_digital(p, 0.02, 1)。
5ctrl_on开关：乘以 ctrl_on，为 0 时控制器不起作用（开环）。
6to vector把函数输出的 2×1 矩阵转成普通的 2 元素向量，外面的模块只接受这种格式。
7, 8u_fb, xh翼角修正量；估计值。
9, 10no link, link没有网络通信，统计输出为 0。

digital_controller.m 每 20 ms 做的五步

1. 预测：xp = Ade*xh + Bde*(上一周期编码器读数的平均 − 配平角)
2. 修正：xh = xp + M*(y − Ce*xp)                 卡尔曼滤波，得到 5 个估计值
3. 控制：du = 前馈*rf − K*(x̂ − Nx*rf) − Ki*xi − Kd*du_prev
4. 积分：xi = xi + 0.02*[ĥ − rf; 测得的俯仰角]      翼角饱和时暂停
5. 滤波：rf = a*rf + (1−a)*r                     参考预滤波，时间常数 0.6 s
输出：有一拍计算延迟，所以这一拍送出的是上一拍算好的 du_prev
步骤说明
1–2 卡尔曼滤波先用模型把上一拍的估计往前推 20 ms，再用新的测量值修正。估计 5 个量：升沉、升沉速度、俯仰角、俯仰角速度，以及一个恒定竖直力偏差（航速或质量与设计值不同时出现）。
3 LQR 控制律状态偏离目标多少就往回拉（K），积分项消除稳态误差（Ki），前馈让控制器直接朝新高度走。Kd*du_prev 是为一拍计算延迟专门设计的补偿项。
4 积分与抗饱和两个积分器：估计高度的误差、AHRS 测得的俯仰角。翼角指令超出 −3° 到 7° 时暂停积分，防止饱和后超调。
5 预滤波把阶跃指令变成 0.6 s 的平滑曲线。比连续设计的 0.3 s 慢，给更大的波浪多留出约 1° 的前翼余量（见控制设计文档 D10）；代价是阶跃约 2.2 s 才稳定。
计算延迟单片机计算需要时间，用 y[k] 算出的指令在下一拍才送出。设计时已把这一拍延迟考虑进去。

这段代码和 sim_digital.m 里的控制循环完全相同。两者在波浪中（无噪声）的升沉相差 0.33 mm，差别来自编码器读数取的是上一个计算步的值。见 run_simulink.m 的 Check 3。

为什么不把连续时间设计的控制器直接搬过来？连续卡尔曼滤波有一个 −287 rad/s 的极点。用前向欧拉法按步长 T 积分时，只有 T < 2/287 ≈ 7 ms 才稳定；按 20 ms 积分会发散。所以控制器和观测器都是直接按离散时间设计的。

软件在环（控制器在另一个进程里）

把控制器从模型里拿出去，放进一个独立运行的程序，模型只当"船"。控制器只能通过网络收到传感器读数、发回翼角指令，和真实船上的电脑一样看不到真实状态。这叫软件在环（software in the loop）。

hydrofoil_sim（船）→ 传感器读数、编码器 →ctrl_server.m（控制器进程）→ 翼角指令 →回到船

External (TCP)：模型这一侧

编号模块作用
4TCP linkMATLAB System 模块，代码在 SilLink.m。每 20 ms：先输出上一拍收到的指令，再把这一拍的读数发给控制器。这样用 y[k] 算出的指令在第 k+1 拍生效，正好是控制器设计时考虑的一拍计算延迟，所以两种实现在算法上完全相同。
5, 6ctrl_on, to vector同 Onboard。
9link[迟到的回复数；控制器计算时间 ms；往返时间 ms]。
模式设置行为用途
锁步sil_lockstep = 1每拍发出读数后等回复再继续，结果是确定的。证明拆成两个进程后系统没变：和 Onboard 的结果逐位相同。
实时sil_lockstep = 0，并打开 Simulink 的实时同步（Run 菜单里的 Simulation Pacing，或 set_param(mdl, 'EnablePacing', 'on')）仿真时间和墙钟同步，两边各跑各的。下一拍到了回复还没来，就继续用旧指令，并记一次"迟到"。测真实时序：通信延迟、抖动、控制器算得太慢的后果。

通信用的是 Java 套接字（MATLAB 自带），没有用 tcpclient：实测 tcpclient 每次收发都要等 Windows 的 15.6 ms 定时器，一个来回 31 ms，超过了 20 ms 的控制周期；Java 套接字一个来回中位数 0.2–0.4 ms。也不需要 Instrument Control 工具箱。

Telemetry：给 3D 画面的数据

9 Send 是 MATLAB System 模块（SilTelemetry.m），每 20 ms 把 1–8 的信号发给 viz/sil_bridge.py，再由它转给浏览器里的 3D 画面。只在 viz_on = 1 时工作；转发程序没开时只给一次警告，仿真照常进行。

怎么运行

1. 启动控制器: 双击仓库根目录的 start_sil.bat，或再开一个 MATLAB、在 matlab/ 里运行 ctrl_server
2. （要看 3D 画面时）启动转发:    python viz/sil_bridge.py，浏览器打开 http://localhost:8000
3. 在这个 MATLAB 里:            ctrl_ext = 1; sil_lockstep = 0; viz_on = 1;
                                load_system('hydrofoil_sim');
                                set_param('hydrofoil_sim', 'EnablePacing', 'on');
                                sim('hydrofoil_sim')

完整的检查和实验在 run_sil.m：锁步等价性、控制器计算时间扫描、随机抖动、线性延迟裕度，结果见 figs/fig20_sil_timing.png。

执行器 Actuators

真实的舵机有两个限制：翼只能转到一定角度，而且转得不能太快。

编号模块作用
1u_cmd输入：要求的绝对翼角。
2Position limit位置限幅，−3° 到 7°。
3Servo error限幅后的指令 − 当前实际翼角。
41 over tau乘以 1/p.tau_act（舵机响应时间 0.02 s）。
5Rate limit转速限幅 ±20°/s。
6Foil angle积分器：转速积分成实际翼角，初值为配平角。
7act_on开关变量。
8Ideal or realact_on 不为零时走上面（真实执行器），为零时指令直接当作实际翼角。
9delta输出：实际翼角。

编号模块作用
1delta输入：实际翼角。
2w输入：前后翼处的水流竖直速度。
3Boat dynamicsMATLAB Function 模块，只有一行：调用 hydrofoil_nl(x, delta, w, p)，返回状态导数。

波浪 Waves

波浪按线性波浪理论计算，可以是规则波（一个正弦分量）也可以是不规则海面（多个分量叠加），由工作区变量 wv 决定。

编号模块作用
1Time仿真时间。
2Wave fieldMATLAB Function 模块，调用 wave_eval(wv, t, p)：算出前后翼处水的竖直速度 w 和传感器下方的波面高度 zeta。Matlab 端的仿真用的是同一个函数。
3, 4wave_on w, wave_on zeta乘以开关变量 wave_on，为 0 时关掉波浪。
5to vector把 2×1 矩阵转成 2 元素向量。
6w输出给船体和线性模型。
7zeta_s输出给传感器。

默认 wv = wave_params(p)：波幅 5 cm、波长 8 m 的规则迎浪，船速 7 m/s 时遭遇频率约 1.3 Hz。换成不规则海面：wv = wave_irregular(p, 0.15, 3.0, 1)（有效波高 0.15 m、峰值周期 3 s、随机种子 1）。

传感器 Sensor

三个传感器，都是实船 SR02 上有的：船头超声波测离水高度，AHRS 测俯仰角，陀螺仪测俯仰角速度。升沉和升沉速度都没有被直接测到。

编号模块作用
1x输入：四个状态。
2Demux拆成升沉、升沉速度、俯仰角、俯仰角速度。升沉速度接终止符（没有传感器测它）。
3sin对俯仰角取正弦。
4ls乘以 3 m：传感器在重心前 3 m，船抬头时船头升高 3 m × sin(俯仰角)。
5zeta_s输入：传感器下方的波面高度。
6, 7Height noise, noise_on h高度噪声，标准差 1 cm，50 Hz；乘以开关 noise_on。
8Ultrasonic height升沉 + 3 m × sin(俯仰角) − 波面高度 + 噪声。波面是减号：水面升高时测到的离水距离变小。
9, 10Angle noise, noise_on th俯仰角噪声，标准差 0.3°。
11AHRS pitch angle俯仰角 + 噪声。
12, 13Gyro noise, noise_on q陀螺噪声，标准差 0.2°/s。
14Pitch-rate gyro俯仰角速度 + 噪声。
15Mux拼成三路。
16y_meas输出：[船头高度；俯仰角；俯仰角速度]，对应 C 矩阵的三行。

怎么用

双击 hydrofoil_sim.slx 打开后直接点运行即可，需要的变量会自动创建。默认是一次完整的闭环演示：50 Hz 数字控制器开（含一拍计算延迟），第 1 秒高度指令升 5 cm，波浪、噪声、执行器限制全开，仿真 10 秒。

想做的事怎么做（在命令行输入）
看波形运行后双击 Scope states
关掉控制器（开环）ctrl_on = 0
开关波浪 / 噪声 / 执行器限制wave_on、noise_on、act_on 设为 1 或 0
改仿真时长Tstop = 20
换高度指令例如 r_ts = timeseries([0;0;0.1;0.1], [0;2;2;20])：第 2 秒升 10 cm
换波浪规则波 wv = wave_params(p, 0.08, 12)（波幅 8 cm、波长 12 m）；不规则波 wv = wave_irregular(p, 0.15, 3.0, 1)
取运行结果out = sim('hydrofoil_sim')，数据在 out.x_nl、out.x_lin、out.delta、out.y_meas、out.xhat、out.link
控制器放到另一个进程（软件在环）先启动 ctrl_server，再 ctrl_ext = 1；实时模式 sil_lockstep = 0，见软件在环
3D 画面viz_on = 1，并先启动 viz/sil_bridge.py
恢复默认clear 后再运行

换控制器设计：例如 dc = design_digital(p, 0.01, 1) 改成 100 Hz，或第三个参数设 0 表示不考虑计算延迟。

模型关闭了 Simulink 的过零检测：执行器限幅在边界附近会频繁切换，过零检测会因此报错。最大步长 0.005 s 已足够精确，和 Matlab 端仿真的处理方式相同。模型没有模拟船体触水，高度低于约 −30 cm 后的结果没有物理意义。
